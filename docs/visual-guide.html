Visual Direction — do not drift

🌀 Slow wide spiral — not a tight corkscrew
📷 Camera outside spiral, looking upward along outer edge
🚪 Graphite doors — thin cyan-white emissive accents only
🪐 One large Jupiter-like planet, one smaller ringed planet
✨ Subtle Milky Way band, sparse starfield
🌫 Fog hides repetition — no true infinite mesh count
✗ No fantasy/medieval style, characters, or physics engine
✗ Never merge stairs into one mesh in Blender
✗ Never use a center pivot on the door panel

Hard rules (every 3D change)

Modular geometry
Keep geometry low-poly, clearly named, export-ready for Three.js
Door pivot
Panel separate from frame; pivot on hinge side — not center
Infinite illusion
Recycle segments + fog + camera — not truly infinite geometry

Constants

ConstantValuePurpose

PLATFORM_STAIR_INDICES[5,11,17,23]Which stairs get a door

Door ↔ Platform mapping

door-0 → stair 5 door-1 → stair 11 door-2 → stair 17 door-3 → stair 23
Each Project in projects.ts has doorIndex 0–3 matching the platform order in PLATFORM_STAIR_INDICES.
⚠ Hit testing uses invisible boxGeometry mesh — not GLB mesh pointer events.
Hinge axis: rotation.y. If panel swings wrong, try rotation.z or check Blender pivot. Do not move pivot in code.

Zustand Store (src/lib/store.ts)

activeDoorId Hovered / focused door
openedDoorId Currently open door
currentProject Project linked to open door
scrollProgress 0 – 1 from scroll offset
Store is written by CameraRig (scrollProgress) and ProjectDoor (door IDs). Read by ProjectOverlay for the HTML UI layer.

What lives in GLB vs. Three.js code

In GLB (Blender)
  • Stairs, platforms, doors geometry
  • Jupiter + ringed planet meshes
  • Door mesh + emissive materials
In Three.js code
  • Starfield (Stars), fog, Milky Way plane
  • Door open animation + preview texture
  • Scroll camera path (CameraRig)
  • Segment recycling (W6)
  • HTML overlay UI

Technologies

Tech Stack

▲
Next.js 15 (App Router)
SSR disabled for Canvas via dynamic(..., {ssr:false}) — do not remove without a plan.
⬡
React Three Fiber + Drei
ScrollControls, useGLTF, Stars, useScroll — R3F wraps Three.js as React components.
✦
GSAP
Door swing animation: panel.rotation.y → -π × 0.55 over 0.8 s with power2.out ease.
◈
Zustand
Lightweight global state: door IDs + scroll progress. Store: src/lib/store.ts
🎨
Tailwind CSS 4
Used for HTML overlay UI only (ProjectOverlay, LoadingScreen). Not inside Canvas.
⬡
Blender → GLB pipeline
Source: blender/stairCelestial.blend → exported to public/models/*.glb. Blender work is complete.
