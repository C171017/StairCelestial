# 02 - Stair And Platform Refinement Prompt

## Use This Prompt In Blender MCP

```txt
Refine the existing staircase and platform blockout into clean modern modular assets.

Project context:
This scene is for a performant Three.js / React Three Fiber portfolio website. The staircase will appear infinite through recycled modular geometry, fog, and camera movement.

Core rule:
Keep it modular, low-poly, clearly named, and export-ready for Three.js.

Goal:
Make the stairs and platforms feel like a premium celestial architectural gallery while keeping the assets simple and reusable.

Requirements:
- Keep each stair segment as a separate object.
- Preserve the slow wide spiral shape.
- Make stair segments look like modern floating architectural slabs.
- Add subtle bevels to stair edges, but keep geometry web-friendly.
- Refine platforms into larger landing slabs where project doors can sit.
- Add simple graphite or glass edge details only if they improve the modern look.
- Keep platforms separate from stairs.
- Keep all naming consistent.

Materials:
- Use matte warm white or soft stone material for stairs.
- Use soft gray material for platforms.
- Use graphite trim only where needed.
- Avoid large texture files.

Design constraints:
- Do not add complex ornaments.
- Do not add tiny decorative details.
- Do not create dense geometry.
- Do not merge stairs into one continuous mesh.
- Do not make the spiral too tight or hard to read.

After refining, summarize:
- number of stair objects
- number of platform objects
- material changes
- any geometry that may be too heavy for web export
```
