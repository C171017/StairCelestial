# 05 - Lighting Fog And Camera Prompt

## Use This Prompt In Blender MCP

```txt
Improve the lighting, fog, and camera composition for a cinematic website hero view.

Project context:
The final website will use a guided third-person camera that scrolls upward around the outer edge of a celestial spiral staircase. The view should be clear, premium, mysterious, and performant.

Core rule:
Keep it modular, low-poly, clearly named, and export-ready for Three.js.

Goal:
Create a strong preview composition that communicates the final website mood.

Camera requirements:
- Use camera_preview as the main preview camera.
- Position it slightly outside the spiral staircase.
- Aim it upward along the outer edge of the staircase.
- Show nearby stairs clearly.
- Show one nearby project door clearly.
- Allow far stairs to fade into fog or mist.
- Keep the large Jupiter-like planet and smaller ringed planet visible but secondary.

Lighting requirements:
- Add a soft key light.
- Add a subtle fill light.
- Add a gentle rim light for stairs and door edges.
- Keep door emissive outlines visible but restrained.
- Make stairs readable against the cosmic background.

Mood:
- modern
- mysterious
- calm
- cinematic
- premium
- not overexposed
- not too dark

Avoid:
- harsh contrast
- blown-out neon
- cluttered starfield
- unreadable dark stairs
- overly dramatic fantasy lighting
- excessive bloom baked into materials

Suggested object names:
- light_key_soft
- light_fill_soft
- light_rim_subtle
- camera_preview

After lighting and camera updates, summarize:
- camera position and target
- light list
- visibility of nearby door
- whether far geometry fades convincingly
```
